Here is the complete source code for **Step #2**. All files follow Mozilla's WebExtensions Manifest V3 guidelines, adhere to clean code practices, and support automatic Firefox/LibreWolf theme matching (dark and light mode) across Linux and Windows.

---

### Project File Structure

Create a root directory named `your-tubes-feed` with the following structure:

```text
your-tubes-feed/
├── manifest.json
├── sidebar/
│   ├── sidebar.html
│   ├── sidebar.css
│   └── sidebar.js
└── icons/
    └── icon.svg

```

---

### File Code Implementation

#### 1. `manifest.json`

```json
{
  "manifest_version": 3,
  "name": "FeedTubes",
  "version": "1.0.0",
  "description": "Displays your custom YouTube feed directly in the Firefox/LibreWolf sidebar.",
  "icons": {
    "48": "icons/icon.svg",
    "96": "icons/icon.svg"
  },
  "sidebar_action": {
    "default_title": "FeedTubes",
    "default_panel": "sidebar/sidebar.html",
    "default_icon": "icons/icon.svg"
  },
  "browser_specific_settings": {
    "gecko": {
      "id": "feedtubes@extension.local",
      "strict_min_version": "109.0"
    }
  }
}

```

### Step #3: Testing & Local Installation Instructions

#### **On Linux & Windows (LibreWolf / Firefox):**

1. Open LibreWolf or Firefox.
2. In the address bar, type `about:debugging` and press **Enter**.
3. Click **This Firefox** (or **This LibreWolf**) on the left panel.
4. Click **Load Temporary Add-on...**
5. Navigate to the `your-tubes-feed` folder and select the `manifest.json` file.
6. Open the sidebar via the browser menu or shortcut (`Ctrl+Sidebar` or `Alt + View > Sidebar > FeedTubes`), and select **FeedTubes**.
